Switching & Routing

Switches and routers are what move data from one computer to another. A switch connects devices on the same local network and forwards frames using MAC addresses. A router connects different networks together and forwards packets using IP addresses.

The gallery below shows the equipment you will learn about on this site. Click any image to see it full size.

Network Equipment Gallery

Router: connects networks and forwards packets by IP address (Layer 3).
Switch: connects devices on a LAN and forwards frames by MAC address (Layer 2).
Firewall: allows or blocks traffic based on security rules.
Access Point: lets wireless devices join the wired network over Wi-Fi.
Cat6 Cable: twisted-pair copper cable with an RJ45 connector (Layer 1).
Server Rack: holds servers, switches, and routers in a data center.
